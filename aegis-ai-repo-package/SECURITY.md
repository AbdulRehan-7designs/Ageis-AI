# Security policy

Aegis AI is an active project and is not certified for safety-critical use.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting (Security tab, "Report a vulnerability") for this repository.

Include what you found, steps to reproduce, and the affected version or commit.

## Handling secrets and data

Never commit `.env`, credentials, real documents, model files, or generated artifacts.
