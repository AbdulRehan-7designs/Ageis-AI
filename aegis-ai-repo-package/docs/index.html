Retrieval pipeline

Hybrid search combines meaning and exact keywords, fuses the rankings inside Qdrant, filters by clearance, then reranks locally. Step through it.

Reciprocal Rank Fusion calculator

A chunk's fused score is the sum of 1 / (k + rank) across both result lists.

Fused score:

A chunk that appears high in both lists beats one that tops only one list.

Clearance filter

Illustrative ordering: INTERNAL < RESTRICTED < CONFIDENTIAL. Filtering happens at query time and is verified again after reranking.

Ingestion and chunking

PDFs are parsed page by page. Tables become single chunks, headers become section titles, and body text is split with overlap so no answer is cut in half.

Production uses 400 tokens with 50 overlap. Tokens are approximated at 4 characters each.
